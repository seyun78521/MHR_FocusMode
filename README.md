# MHR Focus Mode

- Camera-based attack direction control
- Toggle and Hold modes
- Custom key bindings
- Keyboard/Mouse and Controller support
- Crosshair display while Focus Mode is active
- Co-op support

 Ranged weapons are not recommended.
